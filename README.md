# 🎮 Инвентарь - Современная система управления

Мини-приложение на React + TypeScript + Zustand + Tailwind с красивым современным UI, реализующее игровую логику инвентаря.

![Современный дизайн в стиле Glassmorphism с анимациями и градиентами]

## ✨ Основной функционал

- **Добавление предметов** с полями: id, sku, название, иконка, вес, количество
- **Управление количеством** (+ / -) и удаление предмета
- **Стэкинг одинаковых предметов** - количество увеличивается, не создается новая строка
- **Автоподсчёт в реальном времени**: общее количество, суммарный вес, средний вес
- **Персистентность данных** через localStorage (данные не теряются после перезагрузки)
- **Двойное отображение итогов**: под списком и в блоке расширенной статистики

## 🚀 Расширенные возможности

- **Готовые предметы**: выпадающий список с 9 игровыми предметами
- **Фиксированный вес**: вес автоматически устанавливается по типу предмета
- **Расширенная статистика**: средний вес на единицу, самый тяжёлый/легкий предмет
- **Прогресс-бар загрузки**: визуализация заполненности инвентаря
- **Валидация форм**: проверка корректности данных с визуальными подсказками

## 🎨 UI/UX дизайн

- **Glassmorphism стиль**: прозрачные карточки с размытием фона
- **Плавные анимации**: hover эффекты, переходы, появление элементов
- **Современные градиенты**: трехцветные переходы и shimmer эффекты
- **Интерактивные элементы**: масштабирование, подсветка, анимированные иконки
- **Анимированный фон**: плавающие цветные элементы

## 📱 Адаптивность и доступность

- **Responsive дизайн**: на мобильных список превращается в вертикальные карточки
- **Accessibility**: aria-label для всех кнопок, фокус-стили
- **Оптимизация рендеров**: React.memo, useCallback, shallow селекторы

## 🛠️ Технологии

- **React 18** + TypeScript + Vite
- **Zustand** для управления состоянием с persist middleware
- **Tailwind CSS** для стилей с кастомными анимациями
- **ESLint** + Prettier для качества кода

## 🚀 Сборка

```bash
npm install
npm run dev
```

### Продакшн
```bash
npm run build
npm run preview
```

### Линтинг
```bash
npm run lint
```

### Архитектура

- **Компоненты** разделены по ответственности
- **Store** изолирован с типизированными экшенами
- **Селекторы** оптимизированы с shallow comparison
- **Стили** организованы в CSS модулях с Tailwind

### Оптимизация рендеров

- `React.memo` для предотвращения лишних ререндеров
- `useCallback` для мемоизации функций
- `shallow` селекторы в Zustand
- Автоматическое обновление статистики при изменениях

## 🎯 Идеально для GTA 5 серверов

Система инвентаря полностью готова для интеграции в игровые серверы:
- Реалистичная логика веса предметов
- Стэкинг одинаковых предметов
- Красивый игровой интерфейс
- Оптимизированная производительность
